# Probabilistic Models

Covers probabilistic graphical models (directed only): fundamentals of probability, Bayesian networks (representation, exact and approximate inference, MCMC), learning Bayesian networks (ML and Bayesian parameter learning, structure learning), dynamic Bayesian networks, hidden Markov models, and the Kalman filter. Based on the JKU lecture by G. Widmer, WS 2026/27.

**Status:** draft — chapters 1–5 written (Introduction, Fundamentals of Probability, Bayesian Networks: Representation & Semantics, Inference in Bayesian Networks: exact and approximate, Learning Bayesian Networks: general issues and parameter learning)
**Missing:** structure learning in ch. 5 (slide set 5b not yet available); chapters 6–8 are outlines only (DBNs, HMMs, Kalman filter); figure placeholders for the ALARM network (ch. 3) and score following (ch. 7); no exam collection yet

## Notes for editing

- Chapters follow the lecture units: VO 1 → ch. 1, VO 1–2 → ch. 2, VO 3 → ch. 3, VO 4–5 (slide sets 4a exact / 4b approximate inference) → ch. 4, VO 6–8 (slide sets 5 / 5a / 5b, learning) → ch. 5, VO 9 → ch. 6, VO 10–11 → ch. 7, Kalman video → ch. 8.
- Unwritten sections contain `\planned{...}` notes; replace them once the corresponding slides are available.
- `\figureplaceholder{height}{concept}{brief + search hint}{caption}{label}` marks figures that should come from an external image; drop the image into `figures/` and replace the placeholder with `\includegraphics`.
- Notation follows the lecture (Koller & Friedman style): `\Xall` for all variables, bold `\bX`, `\bE` for sets, superscript values `x^0, x^1` with `x^0 = false`, `\Pa`, `\NonDesc`, `\indep`.
- All worked numbers in chapters 2–5 (student network queries, local independencies, parameter counts, VE tables, Gibbs re-sampling distributions) were re-computed by script (`scripts/compute.py`, `scripts/compute5.py`).
- Sampling examples in ch. 4 use real simulation runs with fixed seeds (`scripts/sim.py`). The counts on the 4b slides are invented for illustration; the notes point this out where it matters.
- Plots use the template palette and matplotlib's Computer Modern; regenerate with `python3 scripts/figs.py figures` and `python3 scripts/figs2.py figures` from the course folder.
