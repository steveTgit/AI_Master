# Deep Reinforcement Learning

Covers deep RL methods: DQN, policy gradients (REINFORCE, PPO, SAC), actor-critic architectures, and model-based RL.

**Status:** reviewed — summary covers all 11 chapters; exam collection added, plus a course-specific cheat sheet

## Files

| File | Description |
|------|-------------|
| `summary.pdf` | Complete lecture summary (11 chapters, compiled) |
| `summary.tex` | LaTeX source |
| `exams.pdf` | Curated old exam questions with answer key |
| `exams.tex` | LaTeX source |
| `cheatsheet.pdf` | Dense 2-sided exam cheat sheet (formulas + rules/intuitions/traps) |
| `cheatsheet.tex` | LaTeX source |
| `figures/` | Figure directory |

The cheat sheet is a Deep-RL-specific extra; most courses only ship a summary and an exam collection.

## How to help

Contributions are welcome even when there is no specific task listed. Good places to help:
- Update the notes if lecture material changes.
- Fix errors, typos, broken formulas, or unclear explanations.
- Add examples, derivations, figures, or exam questions where they make a topic easier to study.
- Recompile and commit the PDF after changing a `.tex` file, if you can.

Open an issue if you are unsure; open a pull request directly for small fixes.
